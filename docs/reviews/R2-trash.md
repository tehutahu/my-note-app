## 試す手順

1. フォルダ内でノートを作り一覧へ戻る。
2. 「このフォルダをゴミ箱へ」を押す。フォルダと子孫・所属ノートが通常一覧から消える。
3. 「ゴミ箱を開く」から親フォルダの「復元: 名前」を押す。「ノート一覧へ戻る」で内容が戻る。
4. ノート単独なら「ノートをゴミ箱へ」を使える。
5. ゴミ箱で「完全削除: 名前」を押し、まず「キャンセル」で残ることを試す。不要な試験用項目だけ「完全に削除する」で確定する。

親フォルダが存在しない/削除済みならルートに復元する。以前の別操作で捨てた子は親の復元で勝手に戻さない。完全削除は元に戻せない。
