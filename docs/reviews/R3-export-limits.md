# R3 再取り込みできる範囲での書き出し

- 状態：境界検証成功、ブラウザー確認中・公開前
- 対象：XFER-02/03、UI-03
- レビューURL：https://tehutahu.github.io/my-note-app/ （今回の修正は未反映）

読み込み上限を超えたライブラリーをバックアップとして出力しようとすると、理由とノート単位での書き出し案内を表示します。既存データは保持します。上限は1000ページ、筆跡200万点、PDF単体20MiB、添付合計64MiB、ファイル100MiB。上限ちょうどは利用可能です。

## 証拠

XFER-export-red.logは1001ページをacceptedとしてしまう失敗。XFER-export-all-red.logはページ・点数・単体PDF・添付合計の4期待不一致を確認。最小実装で同じ上限を書き出し時にも確認し、Blob実サイズを使います。XFER-export-green.logはnpm test56/境界6成功。上限ちょうどの書き出しも追加してXFER-export-check.logはnpm test56/check/境界6成功（境界20.39秒）。日本語案内と1001ページ保持のブラウザー試験は追加の回帰検証でありRED先行とは扱いません。

## 操作

通常の「全体バックアップを書き出す」「このノートを書き出す」は同じです。全体の上限超過が表示された場合はノートごとに書き出せます。一つのノート自体が上限を超える場合にも理由を表示します。PDF書き出しは別の選択肢です。
